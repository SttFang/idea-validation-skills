# 实验策略单（第 5 步）

每一项都必须填，填不了就回到前面的步骤。规则依据见 SKILL.md 末尾。

| 项 | 规则 |
|---|---|
| 问题 | 一句话，与第 3 步假设一致 |
| 假设清单 | 每条标 `confirmatory` 或 `exploratory`；确认性假设的数量受第 4 步预算限制 |
| 分流方式 | 自定义实验（高级选项里选 cookie 分流）或广告变体（固定 cookie 分流），比例 50%。50% 只保证两组进入同样多的竞价，展示数和花费会因广告排名不同而不同。接口 v25 看不到分流类型，`split_method` 在界面确认后人工填写。同广告组平均轮播只用于探索 |
| 对照 | 市面上真实在用的通用工具话术（从竞品广告或搜索结果页摘），不是我们自己编的弱对照 |
| 唯一变量 | 只有广告诉求不同 |
| 不变项 | 关键词与匹配方式、出价方式与上限、落地页正文、投放时段、设备、网络。另外：**AI Max 整体关闭**（建系列时就取消；只关搜索词匹配不够，要确认 Text customization 与 Final URL expansion 都已关闭）；**自动应用的建议关闭**，开投前和结束后各查一次「历史记录」；两组广告语言相同（2026-09 起搜索系列按广告语言匹配）；附加素材（附加链接、宣传信息）两组相同；不叠加用于定向或调整出价的受众列表（用客户名单排除已注册用户可以，但两组相同；名单太小时可能无法用于搜索网络，写进局限） |
| 网络 | 只投谷歌搜索。搜索网络合作伙伴默认开启，必须手动关；展示网络扩展不勾选。用接口建系列时显式设 `target_google_search=true`、`target_search_network=false`、`target_content_network=false`，开投前读回确认 |
| 出价 | 人工出价，或「尽可能争取更多点击」并设单次点击价上限；不用智能出价（会强制改为优化轮播，学习期也比实验周期长）。投放期内不改出价、预算、关键词 |
| 关键词 | 词组匹配的意图片段。词组匹配按含义匹配，会命中隐含同义、更具体的说法和中间插词的搜索，词序只在改变含义时才起作用；意图片段界定的是含义范围，不保证搜索词字面包含它。整句长尾只用于文案和落地页标题（单条量太小会被标为搜索量过低，停用不展示） |
| 否定词 | 用**否定词组**（英文引号）写，如 `"claude code"`、`"free"`、`"course"`、`"courses"`、`"job"`、`"jobs"`、`"download"`、`"downloads"`。否定词不匹配近似变体：单复数、拼写变体（如 claude-code）、同义说法逐个列出。只想挡一个精确搜索、保留其长尾时才用否定完全匹配 `[ ]`。加之前对照目标关键词清单，确认不挡自己的目标词。用自定义实验时原系列与实验系列各加一次，或加在账户级否定词列表。否定 `free` 而广告推「Free Episode 1 Script」时，在策略单写明这是固定条件 |
| 人群与设备 | 照抄第 2 步经用户确认的设备、地区、时段、排除项；两组完全相同；原系列与实验系列两边都要设置并核对 |
| 国家 | 按单价档分系列。地区选项默认是「所在地或兴趣」，必须手动改为「所在地」（接口值 `PRESENCE`） |
| 预算 | 用广告变体时可用系列总预算加起止日期（只能新建时选，3–90 天，没有单日 2 倍上限，可能某天集中花）。用自定义实验时先在界面确认该系列能被选为原系列，选不了就用按日预算加结束日期（单日最多花到 2 倍，自然月不超过 30.4 倍）。接口建预算必须显式设 `explicitly_shared=false`。每天查两次花费，重点看是否一组先受限 |
| 主要指标 | 点击率（单位：展示；报表里的点击已剔除无效点击） |
| 次要指标 | 落地后的行为（单位：去重后的落地访客，按第一方访客标识去重，按网址参数 `v=test` / `v=ctrl` 分组）。按点击日期的成熟队列比较：结束后等过转化延迟再取数，并记录取数时间 |
| 护栏指标 | 单次点击价、`Impr. (Top) %` 与 `Impr. (Abs. Top) %`（占自身展示的比例，不用「顶部展示份额」）、搜索词分布、匹配类型分布（出现 AI Max 即不变项被破坏）、无效点击率。自定义实验里搜索词报告与竞价洞察可能拿不到：能拿到就查，拿不到写进局限。搜索词比较的口径和各护栏阈值由用户确认后写进登记，技能不给默认值。两组单次点击价不同可能是诉求带来的质量差异，要和顶部展示比例一起看 |
| 追踪 | 落地页访问带点击标识和广告版本，服务端把 `gclid` 和第一方访客编号绑在一起记录（算设计效应要用）；转化事件开投前在后台确认能收到。投放欧洲经济区、英国、瑞士时，必须有同意横幅和同意模式 v2，按 `region` 设默认拒绝；拿到 `ad_storage` 同意前不写点击标识 cookie；护栏加「两组同意率」 |
| 时间 | 实验周期 1–3 个完整日（要足够短；代价是只能检出更大的差距、覆盖不到完整一周，报告里写明）；广告提前提交、审核通过后再开始计时，留出审核时间；终点只认登记的结束日期或累计花费达到预算上限（先到为准）；样本量只在终点检查，不作为提前结束的条件。用按日预算时，在登记里写明累计花费上限。原系列结束日期不早于实验结束日期 |
| 稳健性与方法 | 点击率假设登记设计效应规则（第一方访客点击分布校正同一用户重复，见 ad-hypothesis-testing）；检验方法由 ad-hypothesis-testing 按计划样本量选定并锁定（小样本 Barnard 精确检验，大样本两比例 z 检验）；需要提前停时只能登记一次中期检查（p < 0.001 才停） |
| 决策映射 | 对每种结论写好行动（见 SKILL.md） |
| 合规 | 假门页写明内测、不收预付、不承诺收入。「不用竞品商标」是比谷歌更严的自我约束：谷歌不限制把商标当关键词，只在投诉后限制广告文案；导航词设否定是为了效率，不是政策要求。不写任何暗示与 Anthropic、OpenAI、YouTube 等有官方合作或授权的说法（属于不可接受的商业行为，会立即封号） |

完成后把策略单转成 ad-hypothesis-testing 的 `prereg.json` 草稿，从它的 `preregistration-template.json` 复制，字段对应：

| 策略单 | 登记字段 |
|---|---|
| 问题、对照、测试诉求、关键词 | `question`、`control_description`、`hypotheses[].test_message`、`hypotheses[].keywords` |
| 分流方式 | `split_method` |
| 预算（累计花费上限） | `budget`；单条假设单独给预算时写 `hypotheses[].budget` |
| 单次点击价 | `cpc` |
| 时间 | `window_days`（1–3）、`interim_looks`（0 或 1）、`interim_after_days` |
| 稳健性 | `design_effect`（`floor`、`band`、`min_match_rate`） |
| 决策映射 | `decisions`（八种结论各写 `action` 与 `step`） |
| 人群与设备 | `audience`（照抄第 2 步） |
| 护栏阈值 | `guardrails`（用户确认的数值） |
| 第 4 步结果 | `planned_n_per_arm`、`daily_units`、`mde_lift_ratio` |
| 基线 | `baseline_rate`、`baseline_source`（写明出处） |

次要指标（落地后的行为）要判输赢时，登记成 `traffic_from` 指向上游假设的下游假设，需要它自己的基线；没有基线就只做描述性观察，不登记、不下结论。

按单价档分系列：每个单价档一个系列、一组假设；某档的量撑不起确认性假设时，该档只做探索性或本轮不投。
